# 组件审查：TodoListCard.vue

> `src/components/todo/TodoListCard.vue` · 155 行 · 今日待办卡：快速添加入口 + 列表/时间线双视图切换 + 超额收纳抽屉

**评级：B**

## 总评

结构上最完整的待办容器卡：分段控件切视图、渐进披露（inlineLimit 超额收抽屉）、空态、四个弹层各司其职，adder/all 按钮的自定义 `:active` 背景与全局 scale 反馈叠得恰到好处。最大的问题不是动效而是一句文案——空态提示「在上方输入框添加」指向一个不存在的输入框（实际是点按钮开抽屉），界面自相矛盾；视图切换瞬跳与一处 `.num` 缺失属打磨项。

## 问题清单

| # | Before | After | Why | 优先级 |
| --- | --- | --- | --- | --- |
| 1 | L86 `hint="在上方输入框添加，带时间的会出现在时间线里"` | 改为与实际交互一致的指引，如 `"点上方「添加待办」，带时间的会出现在时间线里"` | 界面里没有输入框：L70-73 的入口是打开 SmartAddSheet 抽屉的按钮。指令性文案与真实交互矛盾会直接误导新用户，属于界面内部一致性硬伤 | P1 |
| 2 | L76-81 列表 ↔ 时间线由 `v-if / v-else-if` 直接互换，无过渡 | 切换时旧内容 120-150ms 淡出（可叠 2px blur 抹平交叉帧）、新内容淡入，或用 `<Transition mode="out-in">` 包裹两个分支 | 分段控件切换是本卡最高频的状态跳变，瞬跳丢失两视图间的空间连续感；crossfade 是最低成本的连续性补偿 | P2 |
| 3 | L92 `查看全部 {{ todos.length }} 个待办` 数字裸插在文本中 | `<span class="num">{{ todos.length }}</span>` 包裹计数 | 项目已确立 `.num` 惯例（同文件域 HomeTodoCard L35 就包了）；数字宽度变化会引起按钮文字抖动，一致性也破 | P2 |

## 做得好的

- L132-134 / L152-154：`.adder` 与 `.all` 均有自定义 `:active` 背景反馈，叠加全局 scale(0.96)，按下回应充分。
- L43-47 + L91：inlineLimit 超额部分收进「查看全部」抽屉的渐进披露，主页不无限拉长。
- L99-103：「全部待办」抽屉内复用 TodoItem，勾选/编辑交互与主列表完全一致。
- L58-66：视图切换交给通用 SegmentedControl，选择态语言全应用统一。
- 时长缓动全部引用 `--dur-fast` / `--ease-standard` 令牌。

- **P2**：视图切换 crossfade（#2）、计数补 `.num`（#3）。
