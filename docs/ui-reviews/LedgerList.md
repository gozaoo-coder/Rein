# 组件审查：LedgerList.vue

> `src/components/ledger/LedgerList.vue` · 146 行 · 记账流水列表：按日分组 + 日小计，点击行进入编辑

**评级：A-**

## 总评

数据展示层做得干净：分组小计、收入正号绿色 / 支出负号中性灰的符号语言清晰、`.num` 全覆盖、每行的 aria-label 把「编辑什么」念给读屏听。作为纯列表组件它几乎没有动效义务，剩下的都是锦上添花项。
