设计标注

  1. 1列表轨：今天 / 方案日程 / 收件箱 / 习惯循环 + 标签。沿用现有分类体系（date 为空即收件箱），不新造概念。
  2. 2未安排池：date=今天且 start_min 为空的待办。这是"待办"与"日程"的桥 — 拖入时间轴即成时间盒。
  3. 3AI 智能排程：读取睡眠时长、训练负荷、已占用时段，把池中待办放进合适空档；结果逐条可改，遵守"AI 建议 → 用户确认"契约。
  4. 4时间盒：有时长的待办块。date + start_min + duration_min 字段已存在，无需改表；拖拽改位、点选看详情。
  5. 5方案日程一等公民：训练 / 测量块带 program_id 来源标注；改期 / 跳过走 program_schedule_replace 事务回写，引擎与执行永远一致。
  6. 6现在线：过去的块自动变淡，点击"回到现在"；增强后可显示"距下一个安排还有 X 分钟"。
  7. 7详情联动：右栏随选中块切换 — 方案日程显示动作与消耗，待办显示子任务与 AI 排程理由；移动端进三档抽屉（20/40/90）。
  8. 8手机未安排：横滑 chips，长按拖入时间轴，手势体系沿用现有悬浮条拖拽。
  9. 9紧凑轴：手机 pxPerHour 减半、块单行；双指捏合缩放复用 VirtualTimeline 现有能力。
  10. 10悬浮条：保持五槽位停靠，AI 槽位升为常驻一级入口，点击即排程 / 再排。
